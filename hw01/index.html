Public-Key Cryptography on Elliptic Curves

Executive Summary

This project implements a web-based educational simulator to demonstrate Elliptic Curve Scalar Multiplication (\(Q = kG\)) over a finite field \(\mathbb{F}_{17}\). The core implementation transitions between an intuitive sequential addition method (\(O(k)\)) for lower scalars and the cryptographic standard Double-and-Add algorithm (\(O(\log k)\)) for high-performance calculations.

Beyond the deterministic forward computation, a statistical evaluation was conducted on the group structure to assess coordinate distribution, bit entropy, and chaotic behavior, mapping these characteristics against the formal requirements of Cryptographic One-Way Functions and Cryptographic Hash Functions.

Mathematical Framework

The system models the elliptic curve group \(y^2 \equiv x^3 + 7 \pmod{17}\) incorporating the Point at Infinity (\(\infty\)) as the additive identity element.

The modular inverse is computed via the Extended Euclidean Algorithm: \[\gcd(a,p) = a \cdot s + p \cdot t = 1 \implies a^{-1} \equiv s \pmod{p}\]

To satisfy the dual constraint of listing linear execution histories while guaranteeing performance on large inputs, a dispatcher manages execution:

  • \(k \leq 1000\) - Sequential mode: tracks explicit steps \(1G, 2G, \dots, kG\)
  • \(k > 1000\) - Double-and-Add mode: processes scalar via bitwise operations, reducing complexity from \(O(k)\) to \(O(\log k)\)

Group Structure

By scanning the entire finite space \(\mathbb{F}_{17}^2\), the script identifies all valid points lying on the curve. Iterating addition from the base point yields the cyclic subgroup. The group order and structure depende on the chose base point.

Coordinate Distribution

The absolute frequency of coordinates \(x\) and \(y\) across the group shows apparent uniform scattering. Because points jump unpredictably over the plane as \(k\) increments, an observer cannot deduce the neighborhood of \(k\) from coordinate proximity.

Bit Distribution

Converting coordinates to binary representation allows tracking bit density. An ideal entropy goal is a 50% ratio of 1-bits to 0-bits. High entropy prevents frequency analysis attacks.

Avalanche Effect

The Hamming Distance between consecutive output points \(Q_k = kG\) and \(Q_{k+1} = (k+1)G\) measures how many bits flip when \(k\) increments by one. A high average indicates chaotic, unpredictable behavior.

Discussion

Properties meaningful for a cryptographic one-way function (ECC):

  • Hard inversion (ECDLP): computing \(Q = kG\) is trivial via Double-and-Add, but finding \(k\) from \(Q\) requires solving the Elliptic Curve Discrete Logarithm Problem. On this toy curve (\(\mathbb{F}_{17}\)) a lookup table suffices, but over \(\mathbb{F}_p\) where \(p \approx 2^{256}\) it becomes computationally intractable.
  • Absence of subgroup collisions: within the generator's order, every \(k\) maps to a unique point \(Q\). This collision resistance inside the mathematical group is crucial for key pair integrity.
  • Lack of linear correlation: public keys derived from close private keys (e.g. \(k=6\) and \(k=7\)) share no linear trajectory (an asymmetric one-way function must guarantee this).

Properties specifically associated with cryptographic hash functions:

  • Strict avalanche criterion: while ECC exhibits chaotic jumps between inputs, true hash functions mandate that changing a single input bit flips exactly 50% of output bits on average. In ECC this is a byproduct of modular arithmetic; in hash functions it is engineered explicitly via bit-scrambling rounds.
  • Fixed-size output: a hash function compresses any variable-length input into an identical output size (e.g. 256 bits for SHA-256). Elliptic curve points are mathematical coordinates whose bit-length varies depending on the field size.

Conclusion

While elliptic curve multiplication displays practical commonalities with cryptographic hashing, like determinism, high output entropy, and apparent spatial uniformity, it is fundamentally separated by its strict algebraic structure. Hash functions are designed to destroy all mathematical relations to enforce one-way security. Elliptic curves retain a precise geometric group structure that protects against reverse engineering through the hardness of the ECDLP, enabling the mathematical trapdoors required for public-key cryptography and digital signatures such as Ethereum's ECDSA.
