## Tech Stack

The project is built using standard web technologies with minimal external dependencies:

* HTML5
* CSS3
* Vanilla JavaScript (ES6+)
* [MathJax 3.2.2](https://www.mathjax.org/) - LaTeX formula rendering (loaded via CDN)
