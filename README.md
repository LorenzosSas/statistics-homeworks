## Tech Stack

The project is built using standard web technologies. External dependencies are limited to audited cryptographic primitives:

* HTML5
* CSS3
* Vanilla JavaScript (ES6+)
* [MathJax 3.2.2](https://www.mathjax.org/) - LaTeX formula rendering (loaded via CDN)
* [@scure/bip39 1.5.0](https://github.com/paulmillr/scure-bip39) - BIP-39 mnemonic generation (loaded via CDN) 
* [@scure/bip32 2.3.0](https://github.com/paulmillr/scure-bip32) - BIP-32 HD key derivation (loaded via CDN) 
* [@noble/hashes 1.5.0](https://github.com/paulmillr/noble-hashes) - Keccak-256 hashing (loaded via CDN)
* [@noble/curves 1.6.0](https://github.com/paulmillr/noble-curves) - secp256k1 elliptic curve (loaded via CDN)
